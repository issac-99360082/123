Know the moment a page changes.

Watchpost watches any public URL or JSON API, extracts just the part you care about, and sends a signed, structured JSON diff to your webhook the moment it moves. No screenshots to eyeball — an event your code can act on.

API reference Quickstart

What it is good for

Competitor pricing

Watch a .price selector. Get the old and new value, not a red box on a screenshot.

Policy & compliance pages

Terms, licences, regulatory notices. Line-level diffs, retained as an audit trail.

API changelogs & status

JSON path extraction turns a status endpoint into a typed event stream.

Agent & automation triggers

Webhook-first by design: the payload is JSON meant to be consumed by a program.

Quickstart

# 1. Create an account — returns your API key
curl -X POST {{ base_url }}/v1/auth/signup \
  -H 'Content-Type: application/json' \
  -d '{"email":"you@example.com","password":"correct-horse-42"}'

# 2. Preview what would be compared, before saving anything
curl -X POST {{ base_url }}/v1/preview \
  -H "Authorization: Bearer $WATCHPOST_KEY" -H 'Content-Type: application/json' \
  -d '{"url":"https://example.com/pricing","extract_mode":"css","extract_value":".price"}'

# 3. Create the monitor
curl -X POST {{ base_url }}/v1/monitors \
  -H "Authorization: Bearer $WATCHPOST_KEY" -H 'Content-Type: application/json' \
  -d '{
        "name":"Competitor pricing",
        "url":"https://example.com/pricing",
        "extract_mode":"css",
        "extract_value":".price",
        "interval_seconds":3600,
        "notify_webhook_url":"https://your-app.example/hooks/watchpost"
      }'

The payload you receive

POST /hooks/watchpost
X-Watchpost-Signature: t=1767225600,v1=<hmac-sha256>

{
  "event": "monitor.changed",
  "event_id": "evt_142",
  "monitor": { "id": 7, "name": "Competitor pricing", "url": "https://example.com/pricing" },
  "change": {
    "previous_hash": "9f2c…", "current_hash": "41ab…",
    "similarity": 0.94, "lines_modified": 1,
    "modified": [ { "before": "$19.00", "after": "$17.50" } ],
    "unified_diff": "--- previous\n+++ current\n@@ …"
  }
}

How we behave on the sites we monitor

  • robots.txt is respected by default
  • Identifiable User-Agent, no browser impersonation
  • Minimum interval enforced between requests to the same host
  • Public content only — no paywall or login-wall circumvention
  • Private and link-local addresses are refused (SSRF protection)
